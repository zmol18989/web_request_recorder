# 物业收费系统

基于 Python Flask + XAMPP MySQL + 飞书开放平台的本地物业收费系统(中文表名/字段名)。

## 功能

- **登录与账户**:系统需登录使用;「账户/改密码」可修改密码、设置姓名(收费默认经办人)与默认收款方式
- **用户管理(仅管理员)**:新增/编辑/删除收费账号,可设角色(管理员/收费员)、重置密码;收费员无权限访问用户管理
- **导航分组下拉**:顶部导航分「仪表盘 / 收费业务▾ / 基础数据▾ / 报修服务▾ / 系统▾」,当前所在组高亮
- **收费类别(可维护)**:名称、单价、计算方式、适用对象(按房屋/按业主)、**是否需起算日期**均可改。默认类别:
  - 物业费 = 面积 × 1.1元 × 缴费月数(**需起算日期**:起算 = 上次缴至次日,新截止 = 起算月+月数的月末)
  - 水电公摊 = 30元 × 月数(按房屋,**免起算日期**,直接代入)
  - 装修押金 = 2000 元(固定,**按房屋**)
  - 垃圾清运费 = 面积 × 25 元(按房屋)
  - 门禁卡 = 10 元 × 张数(**按房屋**)
  - 停车费 = 月数(**需起算日期**,起算按车牌取该车已缴截止次日;**阶梯价**≥12个月200元/月、不足12个月240元/月;办理前自动校验物业费是否过期)
  - 摆摊费 = 200 元 × 天数(**按房屋**)
  - 装修押金退款 = -2000 元(固定,**按房屋**,负数冲抵本单合计)
  - 充值卡 = 电动车充电卡充值,**金额自由填写**(计算方式 `amount`,按房屋)
- **计算方式**:面积×单价/月×月数(`area_month`)、单价/月×月数(`month`)、面积×单价(`area`)、单价/天×天数(`day`)、数量×单价(`qty`)、固定金额(`fixed`)、自由金额手填(`amount`)
- **待收费明细**:勾选房屋与类别后实时计算金额与起止日期;**金额框可直接修改(手动调整优先)**,右侧实时合计(大号加粗红色)
- **起算日期自动带入**:物业费/停车费自动填入「上次缴至+1 天」,只填缴费月数即可;从未缴过则手动填起算日期
- **挂单(未付款)**:现场付款点「确认收费」;未付款点「挂单」→ 生成单据但**不计入任何统计**;在缴费记录中可筛选「挂单(未付款)」,找到后点「已付款」即计入统计
- **车位**:车辆信息登记车位;办理停车费时明细行可选填/自动带出车位,收费单与缴费明细均显示车位
- **收费统计**:按日期范围统计,含**按收费类别**、**按收款方式**金额汇总、**每日收费折线图**(原生 SVG)+ **导出 Excel**(.xlsx,汇总/每日/类别/方式 4 个工作表)
- **水电公摊**:按年月生成分摊(取物业费缴清覆盖该月最后一天的房屋,按面积占比分摊,四舍五入到分、尾差调到面积最大房);同年月重复生成覆盖;列表显示「水电公摊剩余(元)」列(已缴 − 历次分摊);**导出 Excel**(含剩余列)
- **银行对账**:按日期取系统非现金缴费记录,上传银行流水 Excel(农信/民生/建行,可扩展),按金额精确匹配+日期窗口±3天+备注车牌/房号/车位/业务类型辅助评分,生成「匹配成功/仅系统有/仅银行有」三类对账结果;备注解析调试工具辅助优化匹配规则
- **到期提醒**:列出**已到期**与**30天内到期**的房屋(含姓名/手机号/楼管),支持分页与**导出 Excel**
- **房屋信息**:楼号、房号、面积、姓名、手机号、证件号码、楼管、备注
- **车辆信息**:车牌号(唯一)、手机号、车辆描述、**车位**、**关联房屋(可编辑,强制校验必须属于该手机号名下)**;停车费缴至按车牌显示
- **查询业主**:输入**房号**(如 `3-1201`)、**车牌号** 或 **车位号** → 按手机号列出其名下全部房屋与车辆 → 勾选本次缴费的房屋 → 选择停车费对应的车牌。车辆信息卡片显示手机号与车位;房屋信息一行展示
- **多方式收款**:一笔缴费可拆多种收款方式(如 现金1000 + 微信103.45),合计必须与应收一致
- **停车费校验**:办理停车费时,若某房物业费已过期且本单未补缴覆盖当期的物业费则拦截
- **缴费记录**:按单号/姓名/手机号/日期/状态/**付款状态(已付款/挂单)**查询;收据打印(收费项目表格+网格线,全部居中、双联打印)、中文大写金额、作废/恢复单据、挂单**标记已付款**
- **仪表盘**:今日/本月/累计收费、房屋车辆数、物业费过期房屋清单(分页)、最近收费(分页)

### 报修服务(飞书卡片派单)

- **报修工单**:工单编号 `WX+YYYYMMDD-序号(三位)`(如 `WX20261030-001`);可按**报修类别 / 优先级 / 状态**筛选,分页显示
- **飞书交互式卡片派单**:生成工单时(可选立即派单)把卡片发送到维修师傅的飞书。卡片含工单摘要、故障描述、状态、维修情况输入框、「确认接单」「提交完成」按钮
- **维修师傅自动登记**:任意飞书用户在卡片上点「确认接单」或「提交完成」时,若其 open_id 不在「维修师傅」表,系统自动把他登记进去(姓名优先取飞书通讯录,失败则兜底为 `飞书用户{open_id 后 6 位}`;重名自动加序号;备注标记「飞书点击接单自动登记」);新增/编辑师傅时填手机号也可自动从通讯录取 open_id
- **卡片回调处理**(`card.action.trigger`):解析 open_id / 工单编号 / 表单值 → 状态机流转(接单 待接单→处理中;完工 写入维修情况+完成时间)→ 更新原卡片(已完工后移除表单、显示维修情况与维修照片)
- **飞书照片上传(可选)**:师傅在飞书把照片直接发给机器人 → 系统匹配其最近 7 天内已完工的工单 → 图片 `image_key` 存入 `维修照片` 字段(最多 6 张),**实时下载并缓存到本地** `static/uploads/repairs/`,网页详情页显示缩略图网格
- **报修人通知**:已完工后向报修人的飞书 open_id 推送完工通知(未绑定则跳过并提示)
- **报修统计**:按月份 / 报修类别 / 维修师傅 三种维度统计(工单总数、已完工、未完成、已取消、完工率、平均耗时),支持按月份筛选
- **删除工单(仅管理员)**:仅角色为「管理员」的账号可删除,删除后不可恢复,带二次确认

### 飞书机器人

- 长连接(WebSocket)接收消息,无需公网回调;同时支持 HTTP 路由 `/feishu/card_callback`(URL 校验 / challenge)
- 文字消息查询:输入房号/车牌号/车位号 → 卡片表格回复(显示缴至日期等)
- 输入含「统计/总计/汇总」关键词 → 按物资+类别分组汇总缴费金额
- 图片消息:匹配为「维修后照片」流程(见上)
- **机器人菜单「报修工单」**:点击后机器人发送报修表单卡片(房号、报修类别、优先级、报修人、手机号、故障描述),业主填写提交即生成工单(状态=待接单,报修人 open_id 自动记录,完工后会收到飞书通知)。需在飞书开放平台「应用功能 → 机器人 → 菜单」添加菜单,类型选「发送事件」,事件 key 填 `create_repair`,并在事件订阅中添加 `application.bot.menu_v6`(机器人菜单)
- `card.action.trigger` 事件:接单 / 完成 / 卡片更新 / 菜单表单提交建单
- 启动:`python feishu_bot.py`

## 手动方式(Linux/macOS)

```bash
pip install -r requirements.txt   # 安装依赖
python3 init_db.py                # 建库 wuye_fee + 建中文表 + 默认类别与演示房屋/车辆
python3 app.py                    # 启动收费系统(0.0.0.0:5000)
python3 feishu_bot.py             # 启动飞书机器人(前台)
```

重建已存在的数据:先 `DROP DATABASE wuye_fee` 再运行 `python3 init_db.py`(老库会自动迁移新增列,无需重建)。

## 使用流程

### 收费办理
1. 收费类别(可调单价/公式)→ 房屋信息(录入楼号/房号/面积/姓名/手机号)→ 车辆信息(手机号+关联房屋+车位)
2. 收费办理:输入**房号、车牌号或车位号**(回车或点查询)→ 勾选房屋(显示物业费/停车费已缴至)→ 勾选类别 → 点「添加所选类别」
   → 在明细中填「缴费月数」(物业/停车/水电公摊,物业/停车自动带入起算+1)、「天数」(摆摊)或「数量」(门禁卡)、「充值金额」(充值卡);
   停车费行可填「车位」;金额如与实际有出入可直接在金额框手动改
   → 填写一条或多条收款方式(现金/微信/支付宝/银行卡)→ 右侧实时显示合计 → **确认收费(现场付款)** 或 **挂单(未付款)**
3. 缴费记录:查询(含付款状态筛选)、打印收据、作废/恢复、挂单点「已付款」
4. 水电公摊:选年月、填水费/电费 → 生成分摊 → 查看已收合计与剩余 → 导出
5. 银行对账:选日期 → 选银行 → 上传银行流水 Excel → 点「查询并比对」 → 查看汇总(匹配/仅系统/仅银行/差异)与对账明细表;备注解析调试工具可粘贴银行备注看提取结果,便于排查"仅系统有/仅银行有"的差异原因
6. 到期提醒:查看已到期/30天内到期房屋 → 导出
7. 收费统计:选日期范围查询,看折线图,点「导出 Excel」保存统计表

### 报修服务
1. **维修师傅维护**:先到「报修服务 → 维修师傅」新增一位师傅,**填手机号即可**(open_id 自动从飞书通讯录获取;也可留空,让师傅稍后在飞书点击卡片自动登记)
2. **生成工单**:「报修服务 → 报修工单」→ 新建,选类别/优先级/报修人/故障 → 选师傅并勾选「生成后立即发送飞书卡片」→ 保存
3. **飞书端交互**:师傅收到卡片 → 点「确认接单」(工单自动变处理中、登记师傅 open_id)→ 填写维修情况 → 点「提交完成」(工单已完工、卡片变绿色、通知报修人)
4. **补充维修后照片(可选)**:完工后直接把照片发到与机器人的对话即可;系统自动附加到最近 7 天内已完工的工单,卡片与网页详情页同时显示
5. **报修统计**:「报修服务 → 报修统计」按月份/类别/师傅查看
6. **删除工单**:仅管理员,工单列表右侧「删除」按钮

## 车辆编辑注意事项

- **车牌号必须唯一**:重复车牌保存会被拦截(数据库 UNIQUE 约束)
- **手机号决定归属**:收费界面按手机号把车辆归到业主名下,改手机号会改变车辆归属业主
- **关联房屋必须属于该手机号**:系统强制校验「关联房屋的手机号 == 车辆手机号」
- **车位**:可登记车位号,办理停车费时自动带出并可修改;**收费办理页可直接用车位号查询业主**
- **更换车牌**:车辆列表每行有「换牌」按钮,输入新牌照即可;勾选「迁移历史停车费记录」则把该旧牌名下所有停车费明细改到新牌,停车费「缴至」自动衔接;不勾选则历史仍记在旧牌名下,下次办理停车费需手动填起算日期。换牌会在备注中记录「原车牌 xxx(日期 换牌)」
- **修改关联房屋**后,收费办理页该车牌的下拉会自动优先选中新绑定的房屋
- **删除房屋前**先处理名下车辆(删除或改绑),避免出现无归属车辆
- 作废缴费单不影响车辆信息

## 报修照片存储

- **数据库**:`报修工单` 表 `维修照片` 字段,格式 `image_key|message_id,image_key|message_id,...`(最多 6 张)。`image_key` 是飞书图片资源的 key,`message_id` 是发送该图片的飞书消息 ID(用于后续下载原图)
- **本地缓存**:首次在网页查看工单详情时,Flask 路由 `/repairs/<id>/photo/<idx>` 会调用飞书「获取消息资源」接口下载原图,保存到 `static/uploads/repairs/{image_key}.{ext}`(.jpg/.png/.gif/.webp),之后直接从本地输出
- 旧数据只有 `image_key`(没有 `|message_id`)时网页无法下载,但飞书卡片仍能直接显示
- 飞书卡片已完工状态用 `img` 组件直接渲染所有 `image_key`,不依赖本地缓存

## 说明

- 缴费单号:`P + YYYYMMDD + 4位序号`(唯一,约 17 位)
- **报修工单号**:`WX + YYYYMMDD + 3位序号`(如 `WX20261030-001`)
- **作废单据**与**挂单单据**(挂单=1)均不计入仪表盘/收费统计/导出/飞书机器人缴费统计,也不推进物业费/停车费「缴至」日期
